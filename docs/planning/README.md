## Ground rules everyone should know

- **AI proposes, rules check, people decide.** That is the product and also how we work.
- **Fake data only.** No real employee information, ever, in code, tests or prompts.
- **Be honest about status.** The old competition prototype only worked on one scripted example. Say "we will build", not "we built", until it is built.
- **Your own GitHub account, your own work.** Every member must be able to explain and change their own code.
- **Keep the shared context up to date.** When something is decided or changed, update the overview and the changelog, so the next person (and their AI) sees it.

## Opening the slides

The deck uses the **Plus Jakarta Sans** font (free from Google Fonts). If it is not installed, PowerPoint substitutes another font and the layout may shift. Install it, or present from the PDF.

## Using an AI assistant with this folder

Open this folder in your AI tool and it will find [AGENTS.md](AGENTS.md), which tells it what this folder is and what to read. Ask it questions like "explain the HOLD stage" or "what is my part in the roadmap?".
